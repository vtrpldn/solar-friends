# Heavy route editing

Why: endpoint discovery, shortest-route planning, corridor checks and save validation should not block the desktop interface on maximum-size drafts. Canceling must preserve the proposed connection and exact saved draft. A required route check must not be bypassed by the editor policy that permits unfinished linked drafts.

Large endpoint lookups now use exact-source/class cached workers with close cancellation and explicit Retry. Large shortest/drawn-corridor previews use cancellable preparation and discard results after their source/form changes. Route save/removal await the shared prepared commit. Saves validate the scratch route as a required preflight inside the same preparation, before compiling the actual linked target. Valid preflight plus unfinished linked target returns validation without installing an invalid preview. Small drafts keep immediate native checks. New route previews/checks/saves clear stale cancellation feedback.
