# Astra handoff

- Water and Power list every utility site as a paper card with a resource icon, live tank or battery meters, and operating status. The cards scroll with the sheet. Connection controls and map lens lists still use their existing views.
- Cards can locate a building or Camp, switch supported buildings, and queue river water, purification, or waste service. The drinking reserve and sanitation controls use the existing per-site policies.
- Finances shows shared savings, recorded spend, expansion reserve, and the current grid cost per hour. Pantry shows edible portions, reserve coverage, projected spoilage over the next game day, and powered cold storage.

The finance summary exposes cumulative expenses. An exact today's-spend tile remains open and needs a supported per-day gross spending figure from the finance ledger.

Rustup build, formatting, strict Clippy, and all 334 binary tests passed, including a card action test for Camp. The desktop layout, wheel scrolling, and compiled web build are pending visual review.

The sandbox blocked writes to this worktree's Git index and commit-message files. The changes are in the Astra worktree and preserved as an ordered patch series.
