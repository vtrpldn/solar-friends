# Solar Friends V2 on Bevy

Run the desktop preview from the repository root.

```sh
cargo run --locked --manifest-path bevy-v2/Cargo.toml
```

Choose a biome, landscape, water availability, and land seed, then select **Explore land**. Pan with WASD, the arrow keys, or left drag. Rotate with Q/E or right drag. Zoom with the wheel or +/−, reset the camera with Home, and return to setup with Escape.

The preview currently covers land generation and navigation. Play the full V2 at `/v2/` while the desktop port is in progress.
